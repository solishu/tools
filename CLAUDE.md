# solishu/tools

A collection of independent single-purpose tools, not one project.

- One folder per tool, each with a README: what it does, how to run it, what it needs.
- Tools share no code. A change to one tool touches only its folder, plus its row in the
  top-level README index.
- Adding a tool: create its folder and README, and add a row to the index.
- A tool that gains its own CI, releases, outside users or a recurring scheduled job
  moves to its own repository.
