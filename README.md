# tools

Miscellaneous single-purpose tools. Each lives in its own folder with its own README,
and none depends on another, so any one can move to its own repository later.

| Tool | What it does |
|---|---|
| [`bargaining-transcript/`](bargaining-transcript/) | Turns a long recorded session (YouTube URL or local audio file) into a timestamped, deduplicated transcript for LLM summarisation. macOS. |
